# Terminology

## Terms

| Term | Definition | First seen in |
|------|-----------|--------------|
| **SPA (Single Page Application)** | A web app that interacts with the user by dynamically rewriting the current web page rather than loading entire new pages from a server. | [[References/SubjectV21]] |
| **WebSocket** | Full-duplex persistent communication channel over a single TCP connection, critical for real-time game state synchronization. | [[References/SubjectV21]] |
| **ORM (Object-Relational Mapping)** | A technique that lets you query and manipulate data from a database using an object-oriented paradigm. | [[References/SubjectV21]] |
| **OAuth 2.0** | Authorization framework that enables applications to obtain limited access to user accounts on an HTTP service (e.g., 42 Intra API). | [[References/SubjectV21]] |
| **JWT (JSON Web Token)** | Compact, URL-safe means of representing claims to be transferred between two parties, commonly used for stateless authentication. | [[References/SubjectV21]] |
| **Reverse Proxy (Nginx)** | A server that sits in front of web servers and forwards client requests to those web servers, handling SSL termination (HTTPS). | [[References/SubjectV21]] |
